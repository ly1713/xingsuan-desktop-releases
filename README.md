# 星算助手桌面端 · 发布仓

这个仓库只存放**星算助手桌面端的安装包与自动更新元数据**，不含源码。

源码在私有仓 `ly1713/xingsuan-desktop-app`。

## 下载

各平台的安装包在 [Releases](../../releases) 里，文件名格式：

- Windows：`xingsuan-<版本>-win-x64.exe`（NSIS 安装包，附 `.blockmap` 供增量更新）
- macOS：`xingsuan-<版本>-mac-arm64.dmg` / `xingsuan-<版本>-mac-x64.dmg`
- Linux：`xingsuan-<版本>-linux-x86_64.AppImage`

国内用户走 `https://dl.xsai5.xyz/gh/ly1713/xingsuan-desktop-releases/releases/download/...`（香港节点本地命中，不跨境）。
